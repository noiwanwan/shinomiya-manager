四宮 管理アプリ v1.0

追加した主な機能
- ホームダッシュボード
- Uber売上・件数・稼働時間・時給・平均単価・円/km・ガソリン差引
- Uber CSV出力・メモ検索
- コーティング案件/売上/粗利管理
- 家計 収入/支出/カテゴリ/支払方法/検索/CSV
- カテゴリ別月予算と超過表示
- 固定費の追加・支払済チェック
- レシートOCR（店名/日付/合計自動候補）
- 借入残高・限度額・利用可能額・年利・最低返済・返済優先順
- 複数車両管理
- ODO/オイル交換周期/車検満了
- 整備履歴と費用
- 月次分析・カテゴリ別支出・6か月収支・借入残高
- 目標管理
- JSONバックアップ/復元
- 全収支CSV
- PWAインストール対応
- オフラインキャッシュ

初期値
- 口座 22,425円
- 10月固定費 43,335円相当の項目を登録
- PAL利用可能額83,620円から残高416,380円として初期登録
- レイク50万円、無利息メモ
- スペーシアMK32S / 20後期セルシオを登録
- 10/4 コーティング5万円予定を登録

注意
- データは端末のブラウザlocalStorage保存です。定期的にJSONバックアップしてください。
- OCRはTesseract.jsをCDNから読み込むため、初回OCR利用時は通信が必要です。
- PWAとしてホーム画面に追加するにはHTTPSで公開してください。
