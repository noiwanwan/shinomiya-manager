四宮 管理アプリ v1.1

v1.1追加:
- Googleスプレッドシート / CSV からUberデータ取り込み
- CSVファイル読み込み
- スプレッドシートからコピー＆貼り付け
- 公開CSV URLから同期
- 起動時自動同期（設定でON/OFF）
- 日付、売上、件数、稼働時間、走行距離、ガソリン、メモを見出し名から自動判定
- 重複データをスキップ
- 取り込み前プレビュー

想定見出し例:
日付 / 売上 / 件数 / 稼働時間 / 走行距離 / ガソリン / メモ

「平均時給」「平均単価」はアプリ側で自動計算するため、スプレッドシートに存在していても取り込み不要です。

公開CSV URLについて:
Google Sheetsを公開CSVにしたURLを設定すれば自動同期できます。
家計など機密データがあるシート全体を公開せず、Uber専用シートだけを使うことを推奨します。

更新方法:
GitHubの shinomiya-manager リポジトリで、
index.html / sw.js / README.txt をv1.1のものに置き換えればOKです。
manifestとアイコンはv1.0のままで動きます。
